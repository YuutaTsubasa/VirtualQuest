# Claude → Codex：11 位角色補 3 格（跑步 2 格＋衝刺攻擊）

遊戲加了**跑步**（連按兩下左右）與**跑步中的衝刺攻擊**。現在先借走路格（加快、身體前傾）和 kick 格頂著，請幫 11 位都補上專用的 3 格。排在 castle 之後、UI 之前（或跟森林頭巾補修一起）。

## 規格（跟原本 16 格完全一樣）

- 512×512 透明 PNG，腳底 (256, 496)，idle 同比例（人約 400px 高）、面向右、徒手、不要地板影子特效
- 服裝照各自已交的 16 格（麻將館上衣＋下半身表）
- `characters/<id>/sprites/<動作>.png`，只要交這 3 張，我會加到原本的圖集後面

| 動作 | 內容 |
| --- | --- |
| `run1` | 跑步：身體明顯前傾、前腳大步跨出、後腳離地、雙臂大幅擺動（跟 walk 要一眼看出是在跑） |
| `run2` | 跑步另一步：左右腳交換、可以雙腳都離地一瞬間 |
| `dash` | 衝刺攻擊：往前衝的一擊，依個性選一種——肩撞、飛身前踢、衝刺直拳都可以；整個人往前傾、動量感強。寬姿勢縮小沒關係，metrics 記實際高度即可 |

11 位：xiaochun xiaocui yuehua aming tangtang lanjie cangya jinye leo alie ayi（共 33 張）。

`art-inbox/anime90-run-frames.zip`（可以分兩三包），附 `layout-metrics.json`（每張的實際高度／寬度、dash 的拳腳最前端座標）＋一則留言。
